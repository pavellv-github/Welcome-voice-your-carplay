# CarPlay Welcome

Офлайн Android-приложение для магнитолы Miniboss с Android 12 и ZLink. При первом обнаружении ZLink после загрузки магнитолы оно воспроизводит приветствие по локальному времени, а после разрыва и восстановления — отдельную фразу.

## Что делает MVP

- Использует пять локальных MP3: утро, день, вечер, ночь и восстановление соединения.
- Выбирает фразу по местному времени: 06:00–12:00, 12:01–17:00, 17:01–23:00 и 23:01–05:59.
- Считает восстановлением повторное обнаружение ZLink через 1–5 минут; значение по умолчанию — 2 минуты.
- На время фразы запрашивает временный audio focus с приглушением музыки.
- При активном телефонном звонке ждёт завершения, затем воспроизводит отложенную фразу.
- После перезагрузки запускает мониторинг, если приветствия были включены до выключения.
- Хранит последние 20 диагностических событий локально в приложении.

Минимальная поддерживаемая версия Android — 12 (API 31). Интернет во время работы не нужен.

## Первая установка

1. Установите APK и откройте **CarPlay Welcome** из списка приложений — значок с дорогой и голосовым сигналом.
2. Включите «Включить приветствия».
3. Нажмите «Разрешить доступ к активности ZLink» и включите доступ в системном списке.
4. Нажмите «Разрешить ожидание звонка» и подтвердите разрешения на уведомления и состояние звонка.
5. Откройте ZLink, подключите CarPlay и проверьте журнал после первой фразы.

## Проверка на Miniboss

1. После загрузки магнитолы дождитесь подключения CarPlay.
2. Проверьте, что звучит приветствие, соответствующее времени на магнитоле.
3. Отключите телефон минимум на выбранный интервал, затем подключите снова: должна прозвучать фраза восстановления.
4. Запустите музыку во время фразы: она должна кратко приглушиться и затем вернуться к прежней громкости.
5. Откройте приложение и сохраните текст журнала, если фраза не прозвучала.

## Ограничение ZLink

ZLink не предоставляет документированное публичное Android-событие подключения CarPlay. MVP отслеживает активность пакета `com.zjinnova.zlink` через Usage Access. Поэтому это нужно проверить на конкретной версии ZLink Miniboss: если журнал не содержит «ZLink активен», или строка появляется без реального CarPlay, понадобится отдельная интеграция с фактическим поведением этой версии ZLink.

## Сборка

Проект рассчитан на Android Studio, совместимую с Android Gradle Plugin 8.0.2. Для сборки требуется Android SDK Platform 33 и JDK 17, встроенный в Android Studio.

```bash
./gradlew test :app:assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
