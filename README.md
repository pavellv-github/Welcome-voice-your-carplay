# AI イゴール

Офлайн Android-приложение для магнитолы **Android Bos-Mini A2 (4/64 ГБ, 9″)**. **AI イゴール** воспроизводит локальные голосовые сценарии, приглушая музыку и ожидая завершения звонка. Интерфейс оформлен как тёмная карточная панель и рассчитан на горизонтальный 9-дюймовый экран: сценарий запуска, Bluetooth, аудиосценарии, тест и журнал.

## Режимы запуска

### Bluetooth

1. Дайте приложению доступ к Bluetooth.
2. Выберите одно из уже сопряжённых устройств — обычно телефон, через который работает CarPlay.
3. Выберите задержку от 1 до 5 минут.

После `ACTION_ACL_CONNECTED` выбранного устройства приложение ждёт выбранный интервал и затем воспроизводит приветствие. Разрыв соединения до завершения интервала отменяет ожидание. Повторное подключение после уже сыгранного приветствия в текущей загрузке магнитолы включает дорожку восстановления подключения.

### После загрузки магнитолы

Выключите переключатель «Запуск по Bluetooth», выберите задержку от 1 до 5 минут. После следующей загрузки Android магнитолы приложение ждёт этот интервал и воспроизводит приветствие.

## Общие правила

- Используются пять локальных MP3: утро, день, вечер, ночь и восстановление Bluetooth-подключения.
- Границы времени: 06:00–12:00, 12:01–17:00, 17:01–23:00, 23:01–05:59.
- Первое успешное Bluetooth-подключение после загрузки использует дорожку по времени суток; последующие подключения в этой загрузке — дорожку восстановления. Режим запуска после загрузки всегда использует дорожку по времени суток.
- Во время фразы музыка приглушается через временный audio focus.
- При активном звонке фраза откладывается до завершения звонка.
- В приложении хранится последние 20 событий.

## Первая установка

1. Установите APK и откройте **AI イゴール**.
2. Выберите нужный режим и задержку.
3. Для Bluetooth-режима выдайте разрешение, затем выберите устройство из списка.
4. По желанию выдайте разрешение на состояние звонка и уведомления.
5. Нажмите «Проверить фразу для текущего времени», чтобы проверить звук.

Минимальная версия Android — 8 (API 26); интернет во время работы не нужен.

## Ограничения Bluetooth-режима

Приложение получает стандартные Android-события подключения и отключения Bluetooth. Если телефон был подключён до запуска сервиса, новое приветствие не будет поставлено в очередь: нужен следующий цикл отключения/подключения или режим после загрузки магнитолы.

## Сборка

Проект рассчитан на Android Studio с Android Gradle Plugin 8.0.2, Android SDK Platform 33 и JDK 17.

```bash
./gradlew test :app:assembleDebug
```

APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
